================================================================================
FOLDER STRUCTURE
================================================================================

documents are stored as:
uploads/
├── {tenant_id}/
│   ├── {branch_id}/
│   │   └── umrah/
│   │       └── {family_id}/
│   │           ├── photo_booking_id_timestamp_random.jpg
│   │           ├── passport_booking_id_timestamp_random.pdf
│   │           └── ...

Benefits:
- Tenant/branch isolation
- Easy to manage and organize
- Scalable to millions of files
- Fast file retrieval
- Simple cleanup procedures

================================================================================
DATABASE CHANGES
================================================================================

Added to umrah_bookings table:
- photo_path VARCHAR(500) - Path to photo file
- passport_path VARCHAR(500) - Path to passport file
- photo_uploaded_at TIMESTAMP - When photo uploaded
- passport_uploaded_at TIMESTAMP - When passport uploaded

Index created:
- idx_photo_passport ON (photo_path, passport_path)

Migration script: migrations/add_photo_passport_storage.sql

================================================================================
API ENDPOINTS
================================================================================

1. POST /api/upload_member_documents.php
   Parameters: booking_id, document_type, file
   Response: JSON with file path and status

2. GET /api/get_member_documents.php
   Parameters: booking_id
   Response: JSON with photo_path and passport_path

3. POST /api/delete_member_document.php
   Parameters: booking_id, document_type
   Response: JSON with success status

   → Run migration script
   → Use setup-document-upload.php

4. File size exceeds limit
   → Compress images before upload
   → Use online compression tools
