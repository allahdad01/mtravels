# ✈️ M.Travels Ticket Management System — Features

Your complete airline ticket operations hub. Manage bookings, reservations, refunds, date changes, excess baggage, and support tickets — all in one place.

---

## 🎫 Ticket Bookings (Issued Tickets)

The core of the system — manage all your issued airline tickets.

- **Book Tickets Fast** — Enter passenger details, choose supplier & client, set pricing, and save. Supports one-way and round-trip bookings
- **Smart PDF Import** — Just upload the airline e-ticket PDF and the system automatically reads it: PNR, passenger names, airline, flight numbers, dates, times, cabin class, baggage allowance, and more. Supports all major airlines (FlyDubai, Kam Air, Ariana, Air Arabia, Salaam, and many more)
- **Color-Coded Cards** — Each ticket card shows: PNR, passenger name, client, route, airline, dates, and sold price. Green = paid, amber = partial, red = unpaid — you can see the status at a glance
- **Powerful Search** — Find any ticket by PNR, passenger name, or airline instantly
- **Filter by Status** — All / Booked / Date Changed / Refunded tabs
- **Ticket Details** — Click any ticket to see full info: passenger details, pricing, refund data, date changes, weight purchases, and client/supplier info — all in one modal with 4 tabs
- **Edit or Delete** — Update ticket details anytime or remove incorrect entries
- **Multi-Ticket Invoice** — Select multiple tickets and generate a combined invoice in one click
- **Transaction Management** — For agency clients, track payments with full history

---

## 📋 Ticket Reservations (Pre-Book Holds)

- **Reserve Before Issuing** — Hold tickets for clients without finalizing the booking
- **Same Powerful Features** — Search, filter, edit, view details, manage transactions
- **Convert to Booking** — Track reservations separately until ready to issue

---

## ⚖️ Excess Baggage (Ticket Weights)

- **Add Weight to Any Ticket** — Attach excess baggage purchases to existing tickets
- **Per-Kilogram Pricing** — Enter weight (kg), base price, sold price — profit calculated automatically
- **Full Tracking** — View all weight records with passenger, route, and pricing info
- **Search & Filter** — Find by passenger name, PNR, phone, airline, or city
- **Combined Invoices** — Generate multi-ticket weight invoices

---

## 💰 Ticket Refunds

- **Quick Refund Processing** — Search for a ticket by PNR or passenger name, and the system auto-fills the base and sold prices
- **Penalty Management** — Enter supplier penalty and service penalty — refund amount calculated automatically
- **Two Calculation Methods** — Choose to calculate refund from sold price or from base price
- **Refund Agreement** — Print a professional refund agreement document with one click
- **Transaction Tracking** — Manage refund payments for agency clients
- **Combined Refund Invoices** — Generate invoices for multiple refunds at once

---

## 📅 Date Changes

- **Change Flight Dates Easily** — Update departure date, return date, or both for any ticket
- **Penalty Tracking** — Record supplier and service penalties for the change
- **Auto Calculation** — System recalculates amounts based on your inputs
- **Change History** — All date changes are recorded and visible in the ticket details

---

## 🔍 Single Ticket Detail View

- **Everything in One Place** — See passenger info, client/supplier details, pricing, refund data, date changes, weight purchases, and transaction history on a single page
- **Three Transaction Tables** — Main account, client, and supplier transactions all displayed
- **Quick Actions** — Refund, change date, add weight, edit, or delete right from the detail page

---

## 📄 Multi-Ticket Invoice Generator

The floating action button on every ticket page lets you:

1. Filter by client
2. Select multiple tickets (bookings, reservations, weights, or refunds)
3. Choose currency (USD, AFS, EUR, AED)
4. Add comments
5. Generate a combined professional invoice

---

## 🌐 Client Portal

Your clients get their own view:

- **My Tickets** — View their own ticket bookings and reservations
- **My Weights** — See excess baggage purchases with statistics
- **My Refunds** — Track refund status
- **Ticket Details** — Full detail view for each ticket

## 👑 Super Admin Access

Tenant super admins can view all tickets, reservations, and weights across all branches from dedicated pages.

## 🛡️ Security & Access Control

- **User Roles** — Admin, Finance, Sales, and Clients each have appropriate permissions
- **Tenant & Branch Isolation** — Each branch sees only their own data
- **Secure File Upload** — Validated file types and sizes, path traversal protection
- **Multi-Currency Support** — USD, AFS (Afghani), EUR, AED (Dirham)
