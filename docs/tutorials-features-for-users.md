# 🎓 M.Travels Tutorial Module — Features

Learn how to use every feature of M.Travels with video tutorials, step-by-step guides, and in-app help — available on every page.

---

## 📺 Tutorial Catalog

The Tutorials & Guides page (`admin/tutorial.php`) is your central learning hub:

- **Browse by Category** — Filter tutorials by topic (Tickets, Clients, Finance, HR, Services, Reports, Settings, Security, etc.)
- **Search** — Find any tutorial by keyword
- **Video Players** — Built-in YouTube and Vimeo players with chapter navigation
- **Difficulty Levels** — Beginner, Intermediate, and Advanced
- **Role-Based Content** — Tutorials are automatically filtered based on your role — you only see what's relevant to you

---

## ❓ In-App Help on Every Page

Click the **?** (help) button in the top-right corner of any admin page to get instant contextual help:

1. The system detects which page you're on
2. Loads relevant tutorials for that specific module
3. Click any tutorial to watch the video right there
4. Use chapter markers to jump to specific sections

This works across the entire admin panel — Dashboard, Tickets, Visas, Hotels, Umrah, Accounts, and more.

---

## 🎬 Video Features

- **Chapter Navigation** — Videos with timestamps let you jump to specific topics

## 🛠️ Super Admin — Manage Tutorials

Super admins have full control over the tutorial library:

- **Add Tutorials** — Create new tutorials with title, description, category, page association, video type/ID, chapters, duration, level, sort order, and role visibility
- **Edit Tutorials** — Update any tutorial's details
- **Delete Tutorials** — Remove outdated tutorials
- **Organize** — Set sort order and assign to specific pages for contextual help
