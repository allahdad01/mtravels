# Branch Admin Role — Guide for Clients

## What is a Branch Admin?

The **Branch Admin** is the **manager of a single branch office**. They have full access to everything in their branch — from booking tickets and hotels to managing finances, employees, and clients. Think of them as the day-to-day operations manager.

> **Important:** A Branch Admin can only see data for **their own branch**, not other branches. To see all branches, you need a Tenant Super Admin.

---

## What Can a Branch Admin Do?

### 1. Full Dashboard
The Branch Admin sees the **complete dashboard** with:
- Revenue and booking KPIs
- Financial wealth distribution charts
- Performance overview and sales cards
- Top performers leaderboard
- Supplier and client alerts

### 2. Travel & Services
| Module | What You Can Do |
|--------|----------------|
| **Tickets** | Book tickets, manage reservations, process refunds, change dates, manage ticket weights |
| **Hotels** | Book hotels, process refunds |
| **Umrah** | Book umrah packages, manage services, process refunds and date changes |
| **Visas** | Submit visa applications, process refunds |

### 3. Finance & Accounting
| Module | What You Can Do |
|--------|----------------|
| **Accounts** | Full control — manage main accounts, activate/deactivate suppliers, delete transactions |
| **Debtors** | Full control — manage debtors, delete records and transactions |
| **Creditors** | Full control — manage creditors, delete records and transactions |
| **Sarafi** | Manage money exchange (forex) |
| **Expenses** | Record and manage expenses |
| **Budget Allocation** | Allocate and manage budgets |
| **Additional Payments** | Manage extra payments |
| **JV Payments** | Process joint voucher payments |
| **Reports** | Generate reports for tickets, hotels, visas, umrah |
| **Quarterly Tax Report** | Generate quarterly tax reports (admin only) |

### 4. HR & People
| Module | What You Can Do |
|--------|----------------|
| **HR Dashboard** | Overview of HR metrics |
| **Employees** | Add, edit, view, and manage employees |
| **Performance Reviews** | Conduct employee performance reviews |
| **Attendance** | Manage attendance for all staff |
| **Salary** | Manage salaries, process payments |
| **HR Reports** | Generate HR-related reports |

### 5. Operations
| Module | What You Can Do |
|--------|----------------|
| **Letters (Maktobs)** | Create and manage official letters |
| **Assets** | Manage company assets |
| **Excel Import** | Import data from Excel files |
| **Search** | Search across the system |
| **Suppliers** | Manage supplier records |
| **Clients** | Manage client/customer records |

### 6. Communication
| Module | What You Can Do |
|--------|----------------|
| **Chat** | Send messages to other users |
| **Branch Peering** | Connect with other branches |
| **Email Analytics** | View email sending stats (requires SMTP add-on) |

### 7. Security & Support
| Module | What You Can Do |
|--------|----------------|
| **2FA** | Set up two-factor authentication |
| **Activity Log** | See who did what and when |
| **Support Tickets** | Create and manage support requests |
| **Tutorials** | View training materials |

---

## What a Branch Admin CANNOT Do

- ❌ See data from other branches
- ❌ Change company-wide settings (branding, templates, WhatsApp)
- ❌ Manage subscriptions or payments
- ❌ Create other branches
- ❌ Assign the Tenant Super Admin role
- ❌ Request add-ons

---

## Summary

The **Branch Admin** is the **most powerful role within a single branch**. They have unrestricted access to all modules — travel, finance, HR, operations, and communication. If you manage one office location and need full control, this is the role for you.
