# 🛂 M.Travels Visa Management System — Features

Complete visa application management — from application to approval, document collection, payment tracking, refunds, and re-applications. All in one place.

---

## 📋 Visa Applications

- **Create Applications** — Add a new visa with applicant details (name, passport number, gender, title), destination country, visa type, key dates (received/applied/issued), and financials (base price, selling price, auto-calculated profit)
- **Edit or Delete** — Update any application or remove incorrect entries
- **Smart Search** — Find applications by passport number, applicant name, or phone number instantly
- **Status Filter Chips** — All / Pending / Approved / Issued / Rejected / Cancelled — click to filter instantly
- **Color-Coded Cards** — Each card shows the visa status with a colored badge and edge stripe (green=approved, amber=pending, red=rejected)
- **Payment Progress Bar** — See at a glance whether a visa is paid, partially paid, or unpaid

---

## 🔄 Application Lifecycle

- **Approve** — Move from Pending to Approved with one click
- **Cancel / Reject / Withdraw** — Change status with a reason
- **Re-apply** — Restore a cancelled or rejected visa back to active status, with profit automatically restored
- **Full Status Range** — Pending → Approved → Issued → (Rejected / Cancelled / Withdrawn / Refunded)

---

## 📄 Passport-Style Detail View

- **Real Passport Document Theme** — Each visa detail page looks like a real passport page with navy header, globe emblem, gold brackets, MRZ strip, and hologram effect
- **Status Stamp** — A rotating circular stamp shows the current status (green=approved, amber=processing, red=rejected, blue=pending)
- **All Info in One Place** — Personal details, visa details, financial band with profit, client & supplier contact cards, remarks, and transaction history

---

## 💰 Payments & Transactions

- **Multi-Currency** — USD, Euro (EUR), Afghani (AFS), Dirham (DARHAM)
- **Auto Currency** — Currency auto-fills when you select a supplier
- **Auto Profit Calculation** — Profit = Sold Price − Base Price, calculated automatically as you type
- **Transaction History** — Every payment recorded with date, amount, currency, exchange rate, receipt, and description
- **Add / Edit / Delete Payments** — Full control over payment records
- **Financial Ledger** — Unified view of all transactions with client/supplier/main-account filter pills

---

## ↩️ Refunds

- **Full Refund** — Refund the entire amount with one click
- **Partial Refund** — Refund a portion of the amount
- **Refund Agreement** — Print a professional refund agreement letter with letterhead
- **Print Receipt** — Generate a printable refund receipt
- **Track Processing** — Mark refunds as financially processed when complete
- **Refund Dashboard** — View all refunds with applicant, passport, country, reason, amount, and processed/pending status

---

## 📎 Document Management

- **Drag & Drop Upload** — Just drag files into the upload area (PDF, JPG, PNG, DOC, DOCX, XLS, XLSX — up to 10MB)
- **Document Types** — Choose from pre-defined document types or add a custom name; required documents are marked with a red dot
- **Preview Inline** — See images directly, view embedded PDFs, check status badges (pending/approved/rejected)
- **Delete Documents** — Remove incorrect files anytime

---

## 📄 Multi-Visa Invoice

- **Combine Multiple Visas** — Select several applications for the same client and generate one combined invoice
- **Professional Layout** — Includes totals, currency selection (USD/AFS)
- **Floating Action Button** — Quick access from the applications page

---

## 🌐 Client Portal

Your clients get their own view:

- **My Visas** — Dashboard with total applications, total spent, approved/issued/pending/rejected counts, and a status pipeline bar
- **My Visa Details** — Passport-document themed view with personal info, visa details, and client transactions
- **My Refunds** — Refund history with processed/pending split

---

## 🔔 Notifications

- **WhatsApp Alerts** — Clients automatically receive a WhatsApp notification when a new visa application is created

---

## 🛡️ Security & Access Control

- **User Roles** — Admin, Finance, and Sales each have appropriate permissions
- **Tenant & Branch Isolation** — Each branch sees only their own data
- **Multi-Currency** — USD, EUR, AFS, DARHAM
- **Feature Flags** — Visa module can be enabled/disabled per tenant
