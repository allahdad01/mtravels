# 🔍 M.Travels Global Search Module — Features

Search across your entire system — tickets, visas, hotels, Umrah bookings, expenses, creditors, debtors, and more — all from one search bar.

---

## 🔎 One Search, Everywhere

Type any name, PNR, passport number, phone number, or keyword into the search bar and instantly find matching records across **9 different data types**.

---

## 📋 What You Can Search

| Category | What's Searched |
|----------|-----------------|
| **Tickets** | Passenger name, PNR, phone number |
| **Ticket Reservations** | Passenger name, PNR, phone number |
| **Visa Applications** | Applicant name, passport number, phone |
| **Hotel Bookings** | Guest name, order ID, contact number |
| **Umrah Bookings** | Passenger name, passport number, ID type |
| **Additional Payments** | Description, payment type |
| **Expenses** | Description, category name |
| **Creditors** | Name, email, phone |
| **Debtors** | Name, email, phone |

---

## 🎨 Results at a Glance

Each result is displayed as a color-coded card:

| Type | Color |
|------|-------|
| Ticket | Blue |
| Ticket Reservation | Purple |
| Visa | Orange |
| Hotel | Teal |
| Umrah | Amber |
| Additional Payment | Cyan |
| Expense | Gray |
| Creditor | Red |
| Debtor | Violet |

Each card shows: name, reference number, contact info, client/supplier, route or details, date, status, and amount.

---

## 📊 Filter by Type

After searching, filter results with one click:
- **All** — see everything
- Click any specific type chip to see only that category

---

## 💳 Transaction Panel

Every result card has an expandable **Transactions** panel. Click to see all related main account transactions — debits, credits, amounts, descriptions, and dates — without leaving the search page.

---

## 🔗 Quick Navigation

Each card has a **View** button that takes you directly to that record's detail page for full management.
