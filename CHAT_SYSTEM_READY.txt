ENCRYPTION MECHANISM
================================================================================

Send:
  Message → Encrypt with random IV → Save to DB → ✅

Receive:
  Retrieve from DB → Extract IV → Decrypt → Display → ✅

================================================================================
HOW IT WORKS
================================================================================

Database stores:
  • content: "Hello" (plaintext backup)
  • encrypted_content: "BASE64(IV+encrypted)" (encrypted)
  • is_encrypted: 1 (flag)
  • encryption_key_id: 1 (which key encrypted it)
  • tenant_id_from: 1 (sender's tenant for decryption)

When retrieving:
  • If is_encrypted=1: Decrypt using extracted IV
  • Else: Use plaintext content
  • Display to recipient

================================================================================
ENCRYPTION DETAILS
================================================================================

Algorithm: AES-256-CBC
Key Length: 32 bytes (256 bits)
IV Length: 16 bytes (128 bits)
IV: Random for each message

Storage Format:
  Base64(16-byte-IV + Encrypted-Data)

Decryption:
  1. Base64 decode
  2. Extract IV (first 16 bytes)
  3. Extract encrypted data (remaining)
  4. Decrypt with IV
