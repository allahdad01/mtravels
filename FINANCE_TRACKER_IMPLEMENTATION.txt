================================================================================
  DATABASE SCHEMA
================================================================================

Table: finance_tracker

Columns:
  - id (INT, Primary Key, Auto-increment)
  - date (DATE) - Transaction date
  - type (ENUM: income, expense) - Transaction type
  - amount (DECIMAL 12,2) - Amount value
  - currency (ENUM: usd, afs) - Currency type
  - description (TEXT) - Optional notes
  - branch_id (INT, Foreign Key) - Branch isolation
  - tenant_id (INT, Foreign Key) - Tenant isolation
  - created_by (INT, Foreign Key) - User who created
  - created_at (TIMESTAMP) - Creation timestamp
  - updated_at (TIMESTAMP) - Update timestamp

Indexes:
  - PRIMARY KEY on id
  - INDEX on (branch_id, tenant_id)
  - INDEX on date
  - INDEX on (type, currency)
  - INDEX on created_by

Foreign Keys:
  - branch_id → branches.id (ON DELETE CASCADE)
  - tenant_id → tenants.id (ON DELETE CASCADE)
  - created_by → users.id (ON DELETE CASCADE)

================================================================================
  API ENDPOINTS
================================================================================

All endpoints: api/finance/finance_tracker_actions.php

1. Add Transaction
   POST | action=add_transaction
   Params: date, type, amount, currency, description
   Returns: success, message, transaction_id

2. Get Balances
   GET | action=get_balances
   Returns: success, usd_balance, afs_balance, today_income_*, today_expense_*

3. Get Recent Transactions
   GET | action=get_recent_transactions
   Params: limit (default: 10, max: 100)
   Returns: success, array of transactions

4. Get Single Transaction
   GET | action=get_transaction&id=123
   Returns: success, transaction object

5. Update Transaction
   POST | action=update_transaction
   Params: id, date, type, amount, currency, description
   Returns: success, message

6. Delete Transaction
   POST | action=delete_transaction
   Params: id
   Returns: success, message

7. Exchange Currency
   POST | action=exchange_currency
   Params: from_currency, to_currency, from_amount, exchange_rate, description
   Returns: success, message, conversion details

8. Clear All Data
   POST | action=clear_all
   Params: confirmation (must be "CLEAR_ALL_FINANCE_DATA")
   Returns: success, message, deleted_count
   ⚠️ CAUTION: IRREVERSIBLE!

================================================================================
  TROUBLESHOOTING GUIDE
================================================================================

Issue: "Table doesn't exist"
  Solution: Run migration file again
  Command: mysql -u root -p travelagency_saas < migrations/create_finance_tracker_table.sql

Issue: "Access Denied"
  Solution: Check user role is 'finance_admin'
  Check: SELECT role FROM users WHERE id = ?;

Issue: "CSRF validation failed"
  Solution: Clear browser cache, try incognito/private mode
  Check: Session cookies are enabled

Issue: "Balances not updating"
  Solution: Click "🔄 Refresh" button
  Check: Verify records in database
  Query: SELECT * FROM finance_tracker;

Issue: "API returns 500 error"
  Solution: Check PHP error logs
  File: logs/php_errors.log
  Check: Database connection is valid

See docs/FINANCE_TRACKER_SETUP.md for more detailed troubleshooting.
