USAGE EXAMPLES
================================================================================

Check if Action is Allowed:
```php
if (!RateLimiter::isAllowed($userId, 'messages_per_hour', $tenantId)) {
    error_response('Rate limited', 429);
    exit;
}
```

Record an Action:
```php
RateLimiter::recordAction($userId, 'messages_per_hour', $tenantId, $_SERVER['REMOTE_ADDR']);
```

Get Remaining Quota:
```php
$quota = RateLimiter::getRemainingQuota($userId, 'messages_per_hour', $tenantId);
echo "You have " . $quota['remaining'] . " messages left";
```

Block an IP:
```php
RateLimiter::blockIP('192.168.1.100', 'Too many login attempts', 3600, $tenantId, $adminId);
```

Check if IP is Blocked:
```php
if (RateLimiter::isIPBlocked($_SERVER['REMOTE_ADDR'], $tenantId)) {
    error_response('Your IP is blocked', 403);
    exit;
}
```
