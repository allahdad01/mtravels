USER INTERFACE
==============

Voice Player Layout:
┌─────────────────────────────────────┐
│ [▶] 0:00 ├───○──┤ 0:15             │
│ [1x] [↓] [★] [CC] [i] [🗑] [→]    │
├─────────────────────────────────────┤
│ ▓▓░ ▓░░░ ▓▓▓ ▓░░ (waveform)       │
└─────────────────────────────────────┘

Button Functions:
  ▶  = Play/Pause
  1x = Playback Speed
  ↓  = Download
  ★  = Favorite Toggle
  CC = Transcribe
  i  = Message Info
  🗑 = Delete (own only)
  →  = Forward
