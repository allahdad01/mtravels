================================================================================
                            HOW TO USE
================================================================================

Access the Modules:
  window.chatApp.manager   // ChatManager instance
  window.chatApp.ui        // ChatUI instance
  window.chatApp.api       // ChatAPI instance
  window.chatApp.log()     // Logging function
  window.chatApp.error()   // Error logging

Example Usage:
  // Get contacts
  const contacts = window.chatApp.manager.contacts;
  
  // Select contact
  window.chatApp.manager.selectContact(contactId);
  
  // Send message
  await window.chatApp.api.sendMessage(contactId, 'Hello!');
  
  // Show feedback
  window.chatApp.ui.showSuccess('Message sent!');
  window.chatApp.ui.showError('Something went wrong');

See: IMPLEMENTATION_STARTED.md for more examples
