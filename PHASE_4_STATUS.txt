🆘 COMMON ISSUES & SOLUTIONS
================================================================================

ISSUE: "Call to member function prepare()"
FIX: ✅ FIXED - Updated to use PDO
ACTION: No action needed, already fixed

ISSUE: Tables don't exist
FIX: Apply migration at http://localhost/mtravels/apply_migration_004.php

ISSUE: No logs appearing
FIX: 1) Verify migration applied
     2) Send new message after migration
     3) Check database directly: SELECT COUNT(*) FROM chat_audit_log;

ISSUE: Logs not showing in admin interface
FIX: 1) Clear browser cache
     2) Verify chat_audit_log table exists
     3) Check that ChatAudit is imported in API files

ISSUE: Permission error on migration
FIX: 1) Check database user permissions
     2) Or apply manually via phpMyAdmin
     3) Or grant CREATE TABLE permission to user

ISSUE: Performance problems
FIX: 1) Archive old logs: ChatAudit::archiveOldLogs($tenantId, 90);
     2) Check index exists: SHOW INDEX FROM chat_audit_log;
     3) Monitor table size: SELECT COUNT(*) FROM chat_audit_log;
